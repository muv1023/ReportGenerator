# BAN 517 Inventory Agent Project Report Generator

Instructor-controlled Streamlit app for collecting final responses from student-built Inventory Analytics Agents and generating a standardized PDF for Canvas submission.

## Deploy

1. Create a new GitHub repository.
2. Upload:
   - `app.py`
   - `requirements.txt`
3. Deploy `app.py` in Streamlit Community Cloud.
4. Share the deployed report-generator URL with students.

## Student workflow

1. Finish testing and correcting the student's own Inventory Analytics Agent.
2. Open this report generator.
3. Enter name and deployed Inventory Agent URL.
4. Run each of the nine hardcoded prompts in the student's own agent.
5. Paste the final agent response under the matching prompt.
6. Complete both certifications.
7. Generate and download the PDF.
8. Upload the PDF to Canvas.

The report generator contains no answer key and does not grade the responses.
